# 참여자 설문 (2주 수집 종료 시, 5문항 + 덤프별 1문항)

`docs/participant-guide.md` 의 "2주 뒤에 할 일" 3번. 답은 `cases/<dump-id>/ground_truth.json` 의 `what_user_did / what_fixed_it / confidence=user` 로 옮긴다.
실명·소속은 적지 않는다. 답이 "모름"이어도 그대로 기록한다 — "모름"도 데이터다.

## 전체 (한 번)

1. 이 PC 로 주로 하는 작업은? (게임 / 영상·그래픽 편집 / 3D·CAD / 개발 / 문서·웹 / 기타: ___)
2. 2주 동안 겪은 문제를 모두 고르세요. (프로그램 꺼짐 / 멈춤·응답 없음 / 점점 느려짐 / 화면 깜빡임·검은 화면 / 블루스크린·재부팅 / 없음)
3. 항상 켜져 있는 보안·오버레이·튠 프로그램은? (백신 이름 / 금융·인증 모듈 / Discord·Steam·NVIDIA 오버레이 / Afterburner·RGB 소프트웨어 / 안티치트 게임 / 기타)
4. 문제가 났을 때 스스로 해결해 본 방법과 결과는? (재시작 / 프로그램 재설치 / 드라이버 업데이트 / 오버레이 끄기 / 백신 끄기 / 안 함 / 기타: ___ → 해결됨 / 안 됨 / 모름)
5. 수집기 때문에 불편한 점이 있었나요? (느려짐 체감 / 창이 거슬림 / 경고창 / 없음 / 기타: ___)

## 덤프별 (수집기가 저장한 폴더마다, 기억나는 것만)

- `dumps\<폴더명>` : 그 순간 무엇을 하고 있었나요? 어떤 프로그램들이 함께 켜져 있었나요? 증상은 무엇이었나요? (기억 안 남 가능)

## 팀 기록용 (참여자에게 묻지 않음)

- 참여자 코드(P01…), 수집 기간, 관리자/일반 권한, 덤프 수(major/minor/hidden), 설문 회수일.
- 라벨 신뢰도: 벤더 KB 에 있는 충돌이면 `official`, 설문 답에 근거하면 `user`, 우리 추정이면 `guess`.
