PC 블랙박스 — 참여자 안내 (v0.7 시험판)
==========================================

중앙대학교 캡스톤디자인 5조(정태웅·송민석·남건호)의 연구용 프로그램입니다.
컴퓨터를 쓰다가 프로그램이 꺼지거나, 멈추거나, 느려지는 순간의 "주변 상황"을 기록해서
원인을 찾아 주는 엔진을 검증하는 데 씁니다. 완성된 제품이 아닌 시험판이에요.

평소처럼 컴퓨터를 쓰시면 됩니다. 기록은 자동으로 암호화되어 연구팀에 전송되므로
파일을 따로 보내실 필요가 없습니다.


1. 설치 (1분)
-------------
1) 받은 zip 파일을 오른쪽 클릭 → "압축 풀기" → 문서 폴더처럼 오래 둘 곳에 풉니다.
   (zip 안에서 바로 실행하면 안내 창이 뜨고 멈춥니다.)
2) "PC블랙박스" 폴더의 PcBlackBox.exe 를 실행합니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 "추가 정보" → "실행"을 누르세요.
     학생 프로젝트라 유료 코드 서명이 없어서 뜨는 경고입니다.
   - 관리자 권한은 필요 없습니다. "예/아니요" 권한 창이 뜨지 않아요.
3) 참여 안내를 읽고 "동의하고 시작"을 누르면 끝입니다.
   작업 표시줄 오른쪽(시계 옆)에 남색 동그라미 안에 빨간 점이 있는 아이콘이 생깁니다.
   안 보이면 ^ (숨겨진 아이콘)을 눌러 보세요.


2. 평소에는
-----------
- 아무것도 안 하셔도 됩니다. 프로그램 강제 종료, 응답 없음, 블루스크린, 갑작스러운 꺼짐,
  화면 드라이버 오류는 저절로 기록되고, 알림이 뜹니다.
- 알림을 누르면 "무슨 일이었는지" 짧게 메모할 수 있어요(선택). 메모가 있으면 연구에 큰 도움이 됩니다.

느려지거나 이상할 때 (자동으로 안 잡히는 문제)
- 문제가 있는 프로그램을 쓰던 중에 Ctrl + Shift + F12 를 눌러 주세요.
- "어떤 문제가 있었나요?" 창이 뜨면 증상을 고르고 "보내기". 고르지 않고 닫아도 기록은 남습니다.
- 게임처럼 전체 화면일 때는 창을 띄우지 않고 기록만 합니다(게임이 멈추지 않게).
- 단축키가 안 되면: 작업 표시줄 아이콘 → "지금 문제 기록하기".


3. 무엇을 기록하나요
--------------------
기록하는 것
- 실행 중인 프로그램 이름, 메모리·CPU 사용량, 문제 프로그램이 불러온 부품(DLL) 파일 경로
- Windows 이벤트 로그 중 오류·종료 관련 기록, 그래픽카드 온도·클럭 같은 센서 값
- 설치된 백신·보안 프로그램과 드라이버 이름, 최근 30일 안에 설치한 프로그램 이름
- 직접 고른 증상과 메모, 동의할 때 적은 별명
- 하루 두세 번, 이 프로그램이 잘 동작하는지(기록 개수, 자신의 CPU·메모리 사용량)

기록하지 않는 것
- 키보드 입력, 화면, 창 제목, 문서·사진 같은 파일 내용, 인터넷 사용 기록과 통신 내용
- 사용자 이름과 PC 이름은 저장할 때 %USERNAME%, %COMPUTERNAME% 기호로 바뀝니다.
  파일 경로의 사용자 폴더는 %USERPROFILE% 로 바뀝니다.

언제 기록하나요
- 평소에는 최근 5분의 상태를 메모리에만 담아 두고 계속 덮어씁니다. 디스크에 쓰지 않아요.
- 문제가 생긴 순간에만 그 앞 5분 ~ 뒤 30초를 저장합니다.


4. 어디로 가나요 (보안)
-----------------------
- 저장된 기록은 이 PC에서 연구팀 공개키로 암호화된 뒤 연구팀 Google 계정의 비공개 폴더로 갑니다.
  연구팀이 따로 가진 개인키 없이는 받는 서버를 포함해 누구도 열 수 없습니다.
- 이름 대신 무작위 "참여 ID"로 구분합니다. 아이콘 → "참여 정보"에서 볼 수 있어요.
- 연구 목적(원인 추론 엔진 검증)에만 쓰고, 발표·보고서에는 프로그램 이름과 수치만 씁니다.
- 연구가 끝나면(동의 화면에 적힌 날짜) 모두 삭제합니다.
- 내가 보낸 기록이 궁금하면 아이콘 → "최근 기록 보기" → "폴더 열기".
  (%LOCALAPPDATA%\PcCrashAnalyzer\dumps 에 같은 내용이 남아 있고, 약 300MB 안으로 오래된 것부터 정리됩니다.)


5. 컴퓨터에 미치는 영향
-----------------------
- 읽기만 합니다. 프로그램을 끄거나 설정·레지스트리를 바꾸지 않습니다.
- 연구팀 PC 측정 기준 CPU 평균 0.3% 미만, 메모리 약 120MB.
- 동의할 때 "자동으로 켜기"를 고르면 시작 프로그램 폴더에 바로가기 하나만 만듭니다.
  작업 관리자 → 시작 프로그램 탭에서 그대로 보이고 끌 수 있어요.
- 일부 백신이 "알 수 없는 프로그램"으로 막을 수 있습니다. 그럴 때는 연구팀에 알려 주세요.
  (백신 설정을 바꾸라고 부탁드리지 않습니다.)


6. 잠깐 멈추기 / 그만두기
-------------------------
- 보내기만 멈추기: 아이콘 → "전송 일시중지" (기록은 PC에만 쌓이고, 재개하면 그때 보냅니다)
- 끄기: 아이콘 → "종료" (자동 실행이 켜져 있으면 다음 로그인 때 다시 켜집니다)
- 그만두기: 아이콘 → "참여 그만두기" → 자동 실행이 꺼지고, 고르면 이 PC의 기록을 지우고
  연구팀에 "내 기록 삭제"를 요청합니다. 그다음 프로그램 폴더를 지우면 완전히 끝입니다.
  (폴더만 먼저 지우면 시작 프로그램 바로가기가 남을 수 있어요 — "참여 그만두기"를 먼저 눌러 주세요.)


7. 문의
-------
연구팀 연락처는 아이콘 → "참여 정보"에 있습니다. 궁금한 점, 불편한 점, 그만두고 싶을 때
언제든 편하게 연락 주세요. 참여해 주셔서 정말 감사합니다.
