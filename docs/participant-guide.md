# PC 크래시 블랙박스 수집기 — 참여자 안내 (1쪽)

중앙대학교 캡스톤 프로젝트 "PC Crash Analyzer" 팀(정태웅·송민석·남건호)이 만든 수집기입니다.
2주 동안 PC에 켜 두고, 프로그램이 꺼지거나 멈추거나 느려지는 순간의 **상황 기록**을 모아 원인 추론 엔진을 검증하는 데 씁니다.

## 무엇을 하나

- 평소에는 메모리 안에서만 최근 5분의 상태(실행 중인 프로그램 이름, 센서 값, 자원 사용량, Windows 이벤트 로그)를 순환 저장합니다. **디스크에는 아무것도 쓰지 않습니다.**
- 프로그램 크래시(Windows 이벤트 1000/1001/1002), 블루스크린·전원 이상(41), 디스플레이 드라이버 복구(4101), 하드웨어 오류(WHEA)가 기록되면 **그 순간 전후만** `dumps\` 폴더에 JSON 파일로 저장합니다.
- 느려짐은 자동으로 잡히지 않습니다. 느리다고 느낄 때 **Ctrl+Shift+F12** 를 누르거나, 수집기 창에서 `m` 입력 후 Enter 를 눌러 주세요.
- 24시간치 1분 단위 자원 추세(메모리·GPU 메모리·CPU 상위 프로세스)도 메모리에만 유지하고, 저장 순간에 함께 기록합니다.

## 무엇을 수집하지 않나

- 키보드 입력 내용, 화면, 네트워크 패킷 내용, 파일 내용은 **절대 수집하지 않습니다.**
- 파일 경로와 사용자 이름은 기록되지만 저장할 때 `%USERPROFILE%` 로 치환됩니다.
- 수집기는 **읽기 전용**입니다. 프로그램을 끄거나 설정·레지스트리를 바꾸지 않습니다.
- 인터넷으로 아무것도 보내지 않습니다. 파일은 참여자가 직접 전달할 때만 팀에 옵니다.

## 설치·실행

1. zip 을 원하는 폴더(예 `C:\BlackBox`)에 풉니다. .NET 설치가 필요 없습니다.
2. `수집기 시작.bat` 을 더블클릭합니다. Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행" 을 누릅니다 (코드 서명이 없어서 뜨는 경고입니다).
3. 창이 열린 채로 두면 수집 중입니다. 창을 닫으면 수집이 멈춥니다. 다시 켜려면 bat 을 다시 실행합니다.
4. 관리자 권한으로 실행하면 크래시한 프로그램의 모듈 목록이 더 정확히 잡힙니다(선택). 일반 권한으로도 동작합니다.
5. PC 성능 영향: CPU 평균 0.3% 미만, 메모리 약 100MB (팀 PC 10분 측정).

## 2주 뒤에 할 일

1. 수집기 폴더 안 `dumps\` 를 열어 보고, 보내고 싶지 않은 폴더는 지웁니다.
2. 남은 `dumps\` 를 zip 으로 묶어 팀에 보냅니다.
3. 짧은 설문 5문항에 답해 주세요: 그때 무엇을 하고 있었나 / 어떤 프로그램이 함께 켜져 있었나 / 증상(꺼짐·멈춤·느려짐) / 스스로 해결했나, 어떻게 / 보안·오버레이 프로그램 목록.
4. 수집기를 지우려면 폴더를 삭제하면 끝입니다. 레지스트리·서비스 등록이 없습니다.

## 데이터 취급

- 받은 파일은 팀 저장소(GitHub)에 올리지 않고 팀원 PC의 비공개 폴더에만 둡니다.
- 발표·보고서에는 프로그램 이름과 수치만 쓰고, 참여자를 식별할 수 있는 정보는 쓰지 않습니다.
- 요청하시면 받은 사본을 즉시 삭제합니다.
