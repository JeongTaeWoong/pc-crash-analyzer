# 중간발표 데모 런북 (10/16) — 녹화 우선 구성

**결정(10/12 → 10/13 확정)**: 발표 10분 제약으로 **주 흐름은 90초 녹화 영상 + 라이브 해설**,
라이브 데모는 **Q&A용 비장의 카드**로 전환 (요청 시 즉석 시연). AI 생성 영상은 생략.

## A. 녹화 제작 (발표 2~3일 전 완료)

아래 타이밍 표가 곧 **녹화 스토리보드**다. 실제 화면 그대로, 배경음악·효과 없이 찍는다.

| 녹화 구간 | 내용 | 편집 |
|---|---|---|
| 0:00~0:10 | BlackBox 터미널: `[source]` 5줄 (etw-kernel ok 포함) 보여주기 | 원본 |
| 0:10~0:20 | CrashDummy 실행 → 크래시(스택 출력) | 15초 대기는 점프컷, "⏱ 15초 후 크래시" 자막 |
| 0:20~0:30 | `[trigger]` `[mark]` 로그 클로즈업 | 타임스탬프에 형광 표시 — "크래시 → 감지 ~90ms" |
| 0:30~0:40 | 30초 수집 대기 | 점프컷 + **"⏱ 30초 대기 (편집)"** 자막 — 편집을 숨기지 않는다 |
| 0:40~0:55 | `[dump]` 로그 → 덤프 폴더(4개 파일) 열기 | 원본 |
| 0:55~1:30 | UI [최근 덤프 열기] → 층 판정·후보·근거·점검 순서 | 마우스로 근거 그래프 따라가기 |

- 해상도 1080p, 터미널 폰트 16pt+, 타임스탬프 항상 화면에 보이게
- 재생 중 발표자가 라이브로 해설한다 (영상에 내레이션 녹음하지 않음 — 현장 몰입용)
- 보조 컷(선택): 엔진 샘플 s6(백신 후킹 크래시) UI 화면 5초 — "실제 보안SW 사례면 후킹 DLL이 1순위" 멘트용

체크리스트:
- [ ] 녹화 전 `collector/BlackBox/dumps` 비우기 (방금 생긴 덤프만 보이게)
- [ ] 2테이크 이상 확보, 최종본은 발표 노트북 **로컬 파일**로 (네트워크·클라우드 의존 금지)
- [ ] 프로젝터 해상도(1080p)에서 글자 가독성 최종 확인

## B. Q&A 라이브 카드 (발표 당일 세팅)

발표 내내 노트북에서 BlackBox를 켜 둔다. 클로징 멘트:
**"지금 이 노트북에서도 돌고 있습니다. 원하시면 바로 보여드리겠습니다."**

- [ ] 발표 10분 전: 관리자 터미널에서 BlackBox 실행, `etw-kernel ok` 확인, 그대로 유지
- [ ] 두 번째 터미널에 CrashDummy 명령 입력해 두고 Enter만 남김:
      `collector\experiments\CrashDummy\bin\Release\net8.0\CrashDummy.exe c`
- [ ] UI 켜 둠 (`ui\prototype-python\run_ui.bat`, 상담 창은 오프라인 대역)
- [ ] 요청이 오면: Enter → 15초 담소("보통 이 사이에 질문 하나 더 받습니다") → 트리거 로그 → 30초 뒤 덤프 → UI
- [ ] 라이브 실패 시 부담 없음 — 본 발표는 이미 끝났다. "이벤트 지연이네요, 실측 통계로는 평균 90ms입니다" 하고 종료

## C. 공통 준비

- [ ] 발표자 노트북 사용 필수 (관리자+ETW 필요 — 발표장 PC 불가), 전원 연결
- [ ] Windows 집중 지원(알림 끄기) — 발표 중 카톡 알림 사고 방지
- [ ] `integrate/collector-engine` 최신 pull + Release 빌드 확인
- [ ] 폴백용 사전 생성 덤프 1개 경로 메모 (Q&A 라이브마저 꼬일 때 [스냅샷 열기]용)

## D. 리허설 체크리스트

- [ ] 녹화 재생 + 라이브 해설 동기화 연습 3회 (영상에 입이 따라가는지)
- [ ] Q&A 라이브 카드 2회 실연습 (Enter부터 UI까지, 담소 멘트 포함)
- [ ] 전체 통주 2회, 10분 이내 확인 (장표별 시간은 docs/ppt-prompt.md의 타임테이블 기준)
- [ ] 예상 질문 리허설: "n=12로 뭘 주장?", "이벤트 뷰어·안정성 모니터와 차이?",
      "보안 프로그램이 이 도구를 차단하면?" (→ Defender가 실제로 차단했고 우회 대신 GPU 전환한 실화로 답)
