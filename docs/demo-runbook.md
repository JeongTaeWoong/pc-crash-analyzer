# 중간발표 라이브 데모 런북 (10/16)

목표: "크래시 발생 → 30초 뒤 자동 덤프 → UI 진단·근거·점검 순서"를 3분 안에 라이브로 보여준다.
전제: **발표자 노트북(테스트 PC) 사용** — 관리자 권한 + ETW + 실제 크래시가 필요해 발표장 PC로는 불가.

## 발표 전날 준비

- [ ] `integrate/collector-engine` 최신 pull, 엔진·수집기 Release 빌드 확인
- [ ] 리허설용 덤프 1개 미리 생성해 보존 (폴백 1용) — 경로 메모
- [ ] 데모 전체를 화면 녹화 (폴백 2용, OBS 등) — UI 진단 화면까지
- [ ] `collector/BlackBox/dumps` 비우기(아카이브로 이동) — 시연 때 "방금 생긴 덤프"가 유일하게 보이도록
- [ ] Windows 집중 지원(알림 끄기) 설정 확인 — 발표 중 카톡 알림 사고 방지
- [ ] 터미널 폰트 16pt+, UI 창 크기·배율을 프로젝터 해상도(1080p)에서 확인

## 발표 당일 (시작 10분 전)

- [ ] 전원 연결 (배터리 모드는 클럭이 달라 센서 값이 다르게 보일 수 있음)
- [ ] **관리자** 터미널에서 BlackBox 미리 실행 → `[source] etw-kernel ok` 5줄 확인, 그대로 켜 둔다
      (발표 내내 돌리면 버퍼가 차 있어 덤프에 이벤트가 풍성하게 담긴다)
- [ ] UI 실행해 두기: `ui\prototype-python\run_ui.bat` (상담 창은 오프라인 대역 — API 키·네트워크에 의존하지 않기)
- [ ] 두 번째 터미널에 CrashDummy 명령을 쳐 두고 Enter만 남긴 상태로 대기:
      `collector\experiments\CrashDummy\bin\Release\net8.0\CrashDummy.exe c`

## 데모 시나리오 (3분, 멘트-타이밍 동기화)

| 시각 | 행동 | 멘트 포인트 |
|---|---|---|
| 0:00 | CrashDummy Enter | "크래시를 일으킬 더미 앱입니다. 15초 뒤에 죽습니다. 그동안 —" |
| 0:00~0:15 | BlackBox 터미널 보여주기 | "— 블랙박스는 이미 돌고 있습니다. 지난 5분의 이벤트·센서·DLL 로드가 메모리 링버퍼에만 있고, 디스크엔 아무것도 안 씁니다" |
| 0:15 | 크래시 발생 (스택 출력) | "죽었습니다. 사용자는 아무것도 안 눌렀습니다" |
| 0:15~0:17 | `[trigger]` `[mark]` 로그 지목 | "Windows가 크래시 이벤트를 쓰자마자 ~90ms 만에 감지해 마킹했습니다" |
| 0:17~0:47 | **30초 대기 = 아키텍처 설명 타임** | "마킹 후 30초를 더 수집합니다. 이 사이에 구조를 보면 —" (구조 슬라이드 1장) |
| 0:47 | `[dump]` 로그 → 폴더 열기 | "전후 5분 30초가 덤프됐습니다. 엔진 입력 파일도 함께 생성됩니다" |
| 0:50 | UI에서 [최근 덤프 열기] | "층 판정과 신뢰도, 원인 후보와 **근거**, 비용이 가장 적은 점검 순서까지 — 전부 엔진 계산값이고 UI는 판단하지 않습니다" |
| ~2:00 | 근거 그래프·점검 순서 짚기 | "설문에서 83%가 요구한 '판단 근거'가 바로 이것입니다. 그리고 어떤 조치도 자동 실행하지 않습니다 — 92%가 원한 방식입니다" |

주의: CrashDummy 진단의 원인 후보는 dotnet 런타임 DLL로 나온다(의도된 더미 크래시라서).
"실제 보안SW 충돌 사례면 여기에 백신 후킹 DLL이 1순위로 올라옵니다" 멘트로 연결하고,
필요하면 엔진 샘플 `s6_mvp_av_hook_crash.json`을 UI로 한 번 더 열어 비교(후보 1위: Avast aswhook.dll).

## 폴백 (리허설 때 실패 주입으로 연습할 것)

1. **이벤트 1000이 60초 내 안 뜸** → "미리 받아둔 덤프로 보겠습니다" 하고 전날 덤프를 [스냅샷 열기]로 진행.
   멘트: "감지 지연 실측은 평균 90ms입니다만, 라이브 환경 변수를 감안해 준비한 덤프로 이어가겠습니다"
2. **UI/엔진이 꼬임** → 녹화본 재생으로 전환. 멘트 한 줄 준비: "녹화본으로 보시죠 — 전 과정은 어제 실측 그대로입니다"
3. **노트북-프로젝터 문제** → 처음부터 녹화본 + 슬라이드만으로 진행 가능한 구성 유지
