

5. 시연용 실제 버그 (demo 폴더)

  Godot 4.3 은 JPEG 이 들어 있는 SVG 파일을 가져오다가 꺼집니다 (godotengine/godot 이슈 98341, 4.5 에서 고쳐짐).
  실험실 가상 머신에서 재현한 것과 같은 명령입니다.

  1) 앱을 켜고 [수집 시작] 을 누른 뒤 1분쯤 둡니다 (수집기가 평소 상태를 기록할 시간).
  2) demo\1-Crash.bat 을 실행합니다. Godot 이 프로젝트를 열다가 꺼집니다.
  3) 앱이 새 기록을 잡아 검진 결과를 보여 줍니다. 이어서 [AI 설명...] 을 누릅니다.
{FIXED_YES}  4) demo\2-Fixed.bat 을 실행합니다. 같은 일을 고쳐진 Godot ({FIXED_EXE}) 으로 합니다.
     이번에는 정상으로 끝나고 새 기록이 생기지 않습니다. "업데이트" 조치가 듣는다는 확인입니다.
     (고쳐진 Godot 으로 정상 종료를 확인한 곳은 실험실 가상 머신 두 대입니다. 시연할 PC 에서는 처음 돌리는 것입니다.)
{/FIXED_YES}{FIXED_NO}  4) 고쳐진 Godot 은 아직 이 묶음에 없습니다 (가상 머신에서 먼저 돌려 본 뒤 넣습니다).
{/FIXED_NO}
  두 파일은 실행할 때마다 프로젝트를 처음 상태(project-original)로 되돌리므로 몇 번이든 다시 할 수 있습니다.
  Godot 은 설치되지 않습니다. demo 폴더를 지우면 끝입니다.
  시연할 PC 에서 미리 한 번 돌려 보세요. 지금까지 이 버그를 재현한 곳은 개발 PC 한 대와 실험실 가상 머신 두 대입니다.
